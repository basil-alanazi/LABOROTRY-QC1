# صحة الوالد

موقع لمتابعة قراءات السكر وجرعات الإنسولين، وتستخدمه العائلة كلها بدون تسجيل دخول.

## الإعداد (مرة وحدة)

### 1) Supabase
1. supabase.com/dashboard/new → مشروع جديد باسم `dad-health`
2. انتظر لين يصير Healthy
3. SQL Editor → New query → انسخ كل محتوى `supabase_schema.sql` والصقه → Run
4. Project Settings → Data API → انسخ API URL
5. Project Settings → API Keys → انسخ Publishable key

### 2) Vercel
1. vercel.com → Add New → Project → استورد مستودع `dad-health`
2. Environment Variables:
   - `VITE_SUPABASE_URL` = الـURL
   - `VITE_SUPABASE_ANON_KEY` = الـPublishable key
3. Deploy

### 3) قبل الاستخدام
افتح **الإعدادات** وانسخ جدول الدكتور (Sliding scale) بالضبط: من، إلى، وعدد الوحدات. وعدّل حد الهبوط وأقصى جرعة إذا الدكتور حدد غيرها.

## وش فيه

- **الحاسبة:** تكتب القراءة، فيطلع لك عدد الوحدات حسب جدول الدكتور. التاريخ والساعة يتسجلون تلقائيًا لحظة الحفظ.
  - إذا السكر أقل من حد الهبوط: يطلع "لا تاخذ إنسولين" مع طريقة علاج الهبوط.
  - إذا السكر فوق حد الارتفاع الخطير: يطلع تنبيه "تواصل مع الدكتور".
  - الجرعة ما تتعدى الحد الأقصى أبدًا.
  - إذا فيه جرعة قبل أقل من 3 ساعات: يحذّر من تكرارها.
  - إذا القراءة خارج الجدول: ما يقترح شي، ويطلب التواصل مع الدكتور.
- **القراءات:** جدول لكل يوم فيه الساعة والقراءة والجرعة، ورسم بياني، والمتوسط ونسبة القراءات ضمن الهدف وعدد مرات الهبوط، وزر "طباعة للدكتور".
- **مباشر:** أي قراءة يسجلها أحد من العائلة تظهر عند الكل فورًا.

## ملاحظة
الموقع بدون تسجيل دخول، يعني أي أحد عنده الرابط يقدر يشوف القراءات ويعدّلها. لا تنشر الرابط برّا العائلة.
