# ود

متابعة صحة الوالد

موقع لمتابعة قراءات السكر وجرعات الإنسولين، وتستخدمه العائلة كلها بدون تسجيل دخول.

## الإعداد (مرة وحدة)

الموقع كله على Cloudflare: الصفحات على **Pages**، والبيانات في **D1**، في قاعدة بيانات خاصة اسمها `dad-health-db`، منفصلة عن أي موقع ثاني.

### 1) قاعدة البيانات
جاهزة ومسوية: `dad-health-db`، وفيها الجداول من `schema.sql`. والربط مكتوب في `wrangler.toml` باسم `DB`.

### 2) Cloudflare Pages
1. dash.cloudflare.com → Workers & Pages → Create → Pages → **Connect to Git**
2. اختر مستودع `wad`
3. Build command: `npm run build` — Build output directory: `dist`
4. Save and Deploy
5. إذا الصفحة طلعت "قاعدة البيانات مو مربوطة": Settings → Bindings → Add → D1 database → الاسم `DB` → اختر `dad-health-db` → وبعدها أعد النشر.

### 3) قبل الاستخدام
الخطة الحالية محفوظة جاهزة: Humalog 20 / 20 / 12 قبل الوجبات، وTresiba 40 قبل النوم. إذا غيّرها الدكتور عدّلها من **الإعدادات**.

## وش فيه

- **اليوم:**
  - تسجّل قراءة السكر، والتاريخ والساعة يتسجلون تلقائيًا. الأعمدة نفس ورقة المتابعة: قبل الفطور، وبعد الفطور والغداء والعشاء بساعتين، وعشوائية.
  - جرعات اليوم الأربع، وتضغط "أخذها" فتنسجل بالساعة.
  - إذا آخر قراءة خلال ساعتين كانت هبوط (أقل من 70): الجرعات تتقفل ويطلع تنبيه.
- **تعديل Tresiba:** يشوف قراءة الصيام لأربعة أيام بعد آخر تعديل. إذا كلها أو أغلبها (3 من 4):
  - فوق 200 → **+4**
  - فوق 130 → **+2**
  - غير كذا → نفس الجرعة
  - أي قراءة صيام أقل من 80 → لا تزيد، وكلّم الدكتور
  
  الجرعة ما تتغير إلا إذا ضغطت "اعتمد"، وكل تعديل ينحفظ في سجل.
- **الجدول:** نفس شكل ورقة الدكتور، صف لكل يوم، مع رسم بياني لقراءات الصيام، وسجل تعديلات Tresiba، وزر "طباعة للدكتور".
- **مباشر:** أي شي يسجله أحد من العائلة يظهر عند الكل فورًا.

## ملاحظة
الموقع بدون تسجيل دخول، يعني أي أحد عنده الرابط يقدر يشوف القراءات ويعدّلها. لا تنشر الرابط برّا العائلة.
